# Zhihu--

> 本项目是 [zly2006/zhihu-plus-plus](https://github.com/zly2006/zhihu-plus-plus) 的一个分支（fork），在原作者 Liyan Zhao (zly2006) 的基础上经过大幅修改。
>
> **原项目仍在积极维护**，如果你需要完整的功能（AI 智能过滤、桌面版、本地推荐算法等），请移步原仓库。
>
> 本项目还不够完善，欢迎 PR。

知乎第三方 Android 客户端。

> ⚠️ 此分支是从原项目的一次历史快照衍生的，**并非原项目的最新版本**。
> 许多原有功能在此分支中已被移除或重构，功能完备度可能低于原项目。

## 路线图

### 可用功能

- 登录与账号
  - 支持手机验证码登录、电脑端扫码登录、手动设置 Cookie 登录
  - 强制单账号纯净登录，个人中心独立全屏页面，统一应用与通知设置
- 信息流与推荐
  - 支持切换 **登录状态 / 非登录状态** 下的推荐，防止信息茧房
  - 对齐桌面端 Web API，推荐流完整包含专栏文章与高质量回答
  - 信息流自动过滤商业广告卡片
  - 长按信息流卡片支持快捷标记 **不感兴趣**
  - **稍后阅读（Watch Later）**：支持本地持久化存储，与信息流无缝联动
  - 关注页（顶部常驻关注用户行、动态列表，展示动态来源说明）与知乎日报
  - 搜索（含热搜、历史记录、按排序/类型/时间筛选，用户与话题一键关注）
  - 卡片内容预热缓存（Cache Warming），点击卡片瞬间秒开
- 内容浏览
  - 阅读回答与文章（标题上方原生展示高清文章封面图）
  - 浏览专栏（专栏文章列表与详情导航）
  - 浏览问题详情页（排序、关注、日志 WebView 弹窗浏览、分享、评论）
  - 浏览想法（Pin）详情页（点赞、评论、分享、话题直达、多图画廊浏览）
  - 浏览话题（Topic）详情页与关注
  - 信息流卡片摘要基于自研 AST 引擎即时解析排版
  - 文章、回答与想法采用统一的 Post 阅读页（正文可选中复制、顶栏标题随滚动平滑浮现）
  - 浏览收藏夹及收藏夹内容（卡片展示条目数量与公开/私密状态）
  - 历史记录（支持单条/批量清理，卡片类型智能适配）
  - 展示知乎官方认证徽章
  - 应用内播放知乎视频（基于 AndroidX Media3 ExoPlayer，排版居中与流畅播放）
- 阅读与内容渲染（自研 AST 引擎，告别 WebView）
  - 采用 **AST + Parser + Renderer** 纯原生 Compose 渲染正文
  - 支持段落、多级标题、分割线、链接、列表（含嵌套列表）、表格（自动单元格等高对齐）
  - 支持文本、加粗 / 斜体与 Emoji 行内节点
  - **交互式脚注（Footnote）**：角标精准解析，支持点击交互并在 Material 3 对话框中查看注解详情与链接
  - 引用块指示器使用 `drawBehind` 高性能自绘
  - 数学公式渲染（LaTeX，支持行内公式，深色模式下自适应文本颜色着色）
  - 代码块使用内置等宽字体高亮排版
  - 阅读页自动隐藏的滚动进度条
  - 图片查看器支持动图（GIF）、多图滑动切换与图片预览弹窗
  - 回答页长按保存图片 **无水印**
  - **导出内容**（支持导出为高清长图）
- 社区互动
  - 个人主页**二级导航重构**：直观展示动态轨迹、创作分类（回答/想法/文章/视频/问题）与条目计数，支持按类型和时间排序
  - 关注 / 取消关注 / 拉黑用户 / 屏蔽推荐
  - 支持查看回答赞同者列表，以及关注的人赞同
  - 赞同 / 反对 / 点赞 / 收藏（附带即时 Toast 交互反馈）
  - **单层 Sheet 评论系统**：
    - 基于 Material 3 `ModalBottomSheet` 与 Overlay 输入浮层，杜绝软键盘与抽屉手势冲突
    - 阻尼吸收防底部越界反弹，子评论就地展开与点赞实时同步
    - 深度链接自动定位展开目标评论并高亮提示
  - 头像点击直达作者主页，回答标题点击直达问题详情页
  - 通知与私信：私信气泡采用 AST Inline 渲染，内置原生 `EmojiPicker` 表情面板；通知分类、红点徽标与一键已读
- 系统与体验
  - 动态图标（Android 12+ Material You 动态壁纸取色，低版本采用固定设计配色）
  - 底部导航精简固定为 **首页 / 关注 / 日报 / 稍后再看**，点击快速切换与平滑页面转场，点击当前项回到顶部/刷新
  - 支持 zse96 v2 签名算法（可调用 99% 的网页端 API）与模拟安卓端 API 调用
  - 对齐官方 Deep Link（`zhihu://`）与剪贴板链接识别跳转；统一 URL 解析引擎，知乎内容链接与官方深链直接在应用内无缝打开
  - 支持二维码扫码结果展示和快捷复制
  - 隐私与安全：剥离冗余敏感系统权限，关闭应用自动云备份
  - 开源友好构建：启用 R8 代码裁剪保证小巧体积，但关闭符号混淆（`-dontobfuscate`），崩溃堆栈直观清晰

## 架构调整 (相比原项目 fork 时的快照版本)

| 项目 | 原项目 (zly2006)                | 此分支 (Vodyanitssa) |
| --- |------------------------------| --- |
| 模块架构 | KMP (shared + desktopApp)    | 仅 Android 端 (`:app`)，淘汰 `buildSrc` |
| 包名 | `com.github.zly2006.zhplus`  | `com.zhihuminus` |
| minSdk | 27                           | 28 |
| 架构设计 | 传统分层 / 单一 App 包         | 规范 MVI 领域模块化（post/question/comment/people/follow/history 等） |
| 视频播放 | MediaPlayer                  | AndroidX Media3 (ExoPlayer) |
| 内容渲染 | WebView / Markdown 解析后渲染     | 纯原生 AST + Compose 渲染（告别 WebView） |
| 脚注引用 | 静态文本展示                  | 交互式角标 + Material 3 对话框详情预览 |
| 评论系统 | 多层嵌套 Dialog / BottomSheet  | 单层 Material 3 Sheet + Overlay 悬浮输入法系统 |
| 路由规范 | 私有协议 (`zhplus://` 等)       | 统一对齐官方规范 (`zhihu://`) 与 URL 解析引擎 |
| 启动图标 | 静态图 (ic_launcher)            | 自适应图标 + Material You 动态取色 (ic_zhihuminus_launcher) |
| 账号体系 | 多身份切换管理                | 强制单账号专注登录 |
| 底栏导航 | 多页面可自定义 / 横滑 Pager     | 精简固定（首页/关注/日报/稍后再看），点击平滑切换 |
| 稍后阅读 | 无                           | 支持本地持久化 + 信息流联动 |
| AI / NLP | 支持 (onnx, sentence_embeddings) | 移除 |
| 桌面版 | 支持                           | 移除 |
| 本地推荐算法 | 支持                           | 移除 |
| 阅读朗读 | 支持                           | 移除 |
| 双击手势 | 支持                           | 移除 |
| 遥测 | 支持                           | 移除 |
| 内容创作（写回答 / 发想法） | 支持                           | 移除 |
